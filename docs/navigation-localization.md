# 导航汉化维护与验收

本期仅修改 `apps/v4` 站点导航显示层。正文、示例、组件 API、路由、原始内容标题及注册表资源保持不变。

## 维护方式

- 译名集中在 `apps/v4/lib/navigation-labels.ts`：页面按路径映射，分组按原始标题映射；未配置项回退原名。
- 具体组件名保持英文。未来中文搜索别名添加到 `componentKeywords`，不会改变组件显示名称。
- 顶部“文档”链接仍指向安装页，搜索同时保留 `Docs` 和“安装”等关键词。
- `CommandItem` 的站点包装组件通过隐藏且 `aria-hidden` 的文本向底层 Command 提供搜索索引；不要只修改可见名称或重新引入第二层过滤，否则英文检索和空结果状态可能不一致。
- `useNavigation` 的类型判断与分组过滤继续使用原始英文标题，不能用中文显示标签替换。

## 已验证

- 修改文件的 ESLint 通过，项目 `vue-tsc -b` 通过；使用现有本地二进制执行。
- 非组件内容路径逐项对照映射，无遗漏；隐藏文档不计入范围。
- 浏览器检查首页、简介、安装、组件目录及 Button 页面：顶部、栏目和分组使用中文，组件名保持英文。
- 搜索“安装”“Installation”“组件”“Components”“Button”均返回结果；随机不存在的关键词显示“未找到结果。”；点击 Button 搜索结果可跳转。
- 1280px 桌面、768px 平板、390px 手机下已目视检查相关布局。
- 手机菜单仅有一个首页入口；点击“文档”后菜单收起，并进入安装页。
- 搜索框的方向键选中样式可见，Escape 可关闭弹窗；最终静态产物中用方向键和回车成功跳转到 Button Group 页面，控制台无错误。主题按钮具有“切换主题”无障碍名称。
